# Perfume Website — JANI

Complete luxury perfume website with a shop, cart, Scent Finder quiz, and checkout form.

## What's inside

- 8 perfumes with filters, search, and sort
- Working cart with free delivery over Rs 10,000
- Quick-view with fragrance notes and 50ml / 100ml sizes
- 3-question Scent Finder quiz with personal recommendations
- Collections, Our Story, reviews, FAQ, and newsletter

## Run it

Open `index.html` in a browser, or deploy the repo to GitHub Pages / Vercel — it's a single self-contained static page.

Brand name and WhatsApp number are placeholders and can be updated.
